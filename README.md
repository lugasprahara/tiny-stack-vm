A tiny stack virtual machine in TypeScript: one dependency-free file that runs programs written in make.fun's tiny stack ISA v1 — 36 opcodes, a 256-value data stack, a 64-deep call stack, 256 words of memory, and exact trap semantics for every edge case. It reads each program and its input, then writes the program's output and exit code.

## Run it

```sh
node main.ts
```
