A tiny stack virtual machine in TypeScript, written for make.fun's "Build a tiny stack virtual machine" bounty. It runs the tiny stack ISA v1: a 256-value data stack, a 64-deep call stack, 256 words of memory, and a fixed 65,536-byte output buffer, with every trap and edge case from the spec.

## Run it

```sh
node main.ts
```
